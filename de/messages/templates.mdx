</Warning>

## Was sind WhatsApp-Vorlagen?

WhatsApp-Vorlagen sind von Meta vorab genehmigte Nachrichten, mit denen Sie Konversationen mit Ihren Kunden initiieren können. Im Gegensatz zu regulären Nachrichten ermöglichen Vorlagen das Senden von Werbenachrichten, Benachrichtigungen und Updates an Benutzer, die noch keine Konversation mit Ihnen begonnen haben.

Mit Vorlagen können Sie:

- **Werbenachrichten senden**: Teilen Sie Angebote, Aktionen und Events mit Ihren Kontakten
- **Wichtige Benachrichtigungen**: Informieren Sie über Änderungen, Updates oder Erinnerungen
- **Personalisierung**: Verwenden Sie dynamische Parameter, um jede Nachricht zu personalisieren
- **Kategorisierung**: Organisieren Sie Ihre Vorlagen nach Kategorien (Marketing, Utility, Authentifizierung)

<Tip>Vorlagen sind unerlässlich für Massen-Marketing-Kampagnen und die Aufrechterhaltung proaktiver Kommunikation mit Ihren Kunden</Tip>

## Voraussetzungen

Bevor Sie Ihre erste Vorlage erstellen, stellen Sie sicher, dass Sie haben:

1. **Aktive WhatsApp-Integration**: Sie müssen die WhatsApp Business-Integration konfiguriert und aktiviert haben
2. **Meta Business Portfolio**: Sie benötigen ein verifiziertes Geschäftsportfolio in Meta
3. **WhatsApp Business-Nummer**: Ihre Nummer muss verifiziert und aktiv sein

<Warning>Ohne eine aktive WhatsApp-Integration können Sie keine Vorlagen erstellen oder verwalten</Warning>

## Vorlagenstatus

Vorlagen können während ihres Lebenszyklus verschiedene Status haben:

| Status | Beschreibung | Verfügbare Aktionen |
|--------|-------------|---------------------|
| **Ausstehend** | Die Vorlage wurde eingereicht und wird von Meta überprüft | Details anzeigen, auf Genehmigung warten |
| **Genehmigt** | Meta hat die Vorlage genehmigt und sie ist einsatzbereit | In Kampagnen verwenden, Details anzeigen, duplizieren |
| **Abgelehnt** | Meta hat die Vorlage abgelehnt | Ablehnungsgrund anzeigen, neue Version erstellen |
| **Pausiert** | Die Vorlage wurde vorübergehend pausiert | Reaktivieren, Details anzeigen |

### Häufige Ablehnungsgründe

Wenn Ihre Vorlage abgelehnt wird, wird Meta einen spezifischen Grund angeben. Die häufigsten Gründe sind:

- **Verbotener Inhalt**: Spam, irreführender Inhalt oder Inhalt, der Richtlinien verletzt
- **Falsche Kategorie**: Die Kategorie stimmt nicht mit dem Inhalt überein
- **Falsches Format**: Fehler in Parametern, Schaltflächen oder Struktur
- **Marketing-Richtlinien**: Verstoß gegen spezifische Marketing-Richtlinien
- **Fehlende Informationen**: Erforderliche Felder unvollständig oder falsch

<Danger>
Wenn Ihre Vorlage abgelehnt wird, überprüfen Sie den von Meta angegebenen Grund und beheben Sie die Probleme, bevor Sie eine neue Version erstellen. Mehrfach abgelehnte Vorlagen können sich auf Ihr Konto auswirken.
</Danger>

## Best Practices für Vorlagen

<CardGroup cols={2}>

  <Card title="Richtige Kategorie" icon="tag">
    Wählen Sie immer die Kategorie, die den wahren Zweck Ihrer Vorlage am besten beschreibt. Dies beschleunigt den Genehmigungsprozess.
  </Card>

  <Card title="Überprüfung vor dem Einreichen" icon="check-circle">
    Überprüfen Sie immer die Vorschau vor dem Einreichen. Überprüfen Sie Rechtschreibung, Grammatik und dass alle Parameter korrekt definiert sind.
  </Card>

  <Card title="Beschreibende Namen" icon="file-text">
    Verwenden Sie Namen, die den Zweck der Vorlage klar beschreiben. Dies erleichtert die Verwaltung, wenn Sie viele Vorlagen haben.
  </Card>

  <Card title="Richtlinienkonformität" icon="shield">
    Machen Sie sich mit den WhatsApp- und Meta-Inhaltsrichtlinien vertraut, bevor Sie Vorlagen erstellen, um Ablehnungen zu vermeiden.
  </Card>
</CardGroup>

<Warning>Pausierte Vorlagen können nicht in neuen Kampagnen verwendet werden, aber bestehende Kampagnen, die sie verwenden, funktionieren weiterhin</Warning>

<Accordion title="Häufig gestellte Fragen">

### Wie lange dauert es, bis Meta eine Vorlage genehmigt?

In der Regel genehmigt oder lehnt Meta Vorlagen innerhalb von 24 Stunden ab. Diese Zeit kann jedoch variieren je nach:
- Der Vorlagenkategorie (Marketing-Vorlagen können länger dauern)
- Dem Anfragevolumen von Meta
- Der Komplexität der Vorlage

### Kann ich eine Vorlage nach dem Einreichen zur Genehmigung bearbeiten?

Nein, sobald sie zur Genehmigung eingereicht wurde, können Sie die Vorlage nicht mehr bearbeiten, bis sie genehmigt oder abgelehnt wurde. Wenn Sie Änderungen vornehmen müssen, müssen Sie eine neue Vorlage erstellen.

### Was passiert, wenn meine Vorlage abgelehnt wird?

Wenn Ihre Vorlage abgelehnt wird, können Sie den spezifischen Ablehnungsgrund einsehen. Sie können eine neue Version erstellen, indem Sie die genannten Probleme beheben. Es gibt keine Begrenzung, wie oft Sie versuchen können, eine Vorlage zu erstellen.

### Wie viele Vorlagen kann ich haben?

Es gibt keine strikte Begrenzung für die Anzahl der Vorlagen, die Sie erstellen können, aber es wird empfohlen, nur die Vorlagen zu behalten, die Sie wirklich benötigen, um Ihr Konto organisiert zu halten.

### Kann ich dieselbe Vorlage in mehreren Kampagnen verwenden?

Ja, sobald eine Vorlage genehmigt ist, können Sie sie in so vielen Kampagnen verwenden, wie Sie möchten. Dies ist besonders nützlich für häufig verwendete Vorlagen.

### Sind dynamische Parameter obligatorisch?

Nein, dynamische Parameter sind optional. Sie können Vorlagen ohne Parameter erstellen, wenn die Nachricht statisch ist und keine Personalisierung erfordert.

### Kann ich Emojis in Vorlagen verwenden?

Ja, Sie können Emojis in Vorlagen verwenden, aber verwenden Sie sie in Maßen und stellen Sie sicher, dass sie für den professionellen Kontext Ihres Unternehmens angemessen sind.

</Accordion>

Esta es la Herramienta de **Búsqueda de Google** para un chatbot. Permite habilitar o deshabilitar el uso de Google Search. 

El campo de texto se usa para definir las reglas o situaciones específicas (ej. precios actuales, información reciente) en las que el chatbot debe activar automáticamente la búsqueda en Google para obtener información actualizada.
